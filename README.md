# api-doc-standard

遵循仓库权威契约、载体、模板和发布流程，编写、整理或审核调用方可使用的中文 API 文档。提供完整性检查、发布核对和默认功能页模板。

## 使用

提供功能范围、契约来源、相关材料和本次交付目标。页面组织与载体遵循项目规定，各操作均按所属载体核对完整性。新增接口可提供已确认方案，记录目标契约及实现验证状态。

### 编写或整理本地文档

```text
使用 $api-doc-standard。
功能：<业务功能>
契约来源：<已确认需求与设计、同版本声明或真实入口>
已有文档：<相关材料>
交付目标：<本地业务补充或完整功能页>

请按仓库模板整理调用说明，核对字段来源、业务语义和结果处理。
```

### 文档审核

```text
使用 $api-doc-standard。
文档：<待审核材料>
契约来源：<同版本机器契约或真实入口>

请核对文档与已确认契约的完整性和一致性，
给出差异、调用方影响和处理建议。
```

### 发布或同步

```text
使用 $api-doc-standard。
维护源：<已核对的文档与契约>
目标页面：<平台及页面身份>
本次操作：更新该页面

请按项目发布流程同步并回读核对，交付页面与实际验证结果。
```

默认模板用于完整功能页；项目提供的结构优先。机器契约、业务补充和发布页分别承接项目规定的内容，发布操作沿本次目标与授权执行。
