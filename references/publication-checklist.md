# API 文档发布核对

适用于用户请求发布或同步 API 文档。仓库的载体、合成方式、平台、模板和发布流程优先；使用已配置工具及本次授权范围。

## 发布准备

按[完整性核对](contract-checklist.md)检查适用来源与待发布内容，定位全部维护源和目标页面，记录适用版本、操作标识及必要页面身份。核对契约、示例、业务补充和链接；有未确认差异时先回到维护源解决。

页面与附件采用项目允许发布的字段和脱敏数据。发布凭据由授权工具上下文持有，认证示例使用占位符。

项目区分维护源与合成产物时，完整页按约定位置生成。合成、平台适配和回读保持维护源职责，契约内容在其权威来源维护。

## 写入与回读

- 读取目标现状，优先更新已有页面，按真实差异和平台支持方式写入。
- 平台有版本号、哈希或其他并发标识时携带读取值；否则写入前重读，有变化时先核对范围。
- 保留本次范围之外的内容。写入失败或结果待核实时先回读，再判断实际状态与后续动作。
- 写后回读标题、字段、嵌套结构、示例和站内链接，与准备好的页面及权威来源比较。
- 维护源在发布期间变化时重新核验；本地业务补充的内容和职责按项目约定保持。

## 交付

列出维护源、全部已更新页面及实际验证结果，注明未执行、未发布或未关闭项。兼容影响和后续接入条件按项目记录方式交付；文档写入、业务调用和消息发送分别按各自授权执行。
